# StudyFlow — COP3874 Activity 2

A responsive, component-based React study task planner.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the localhost URL shown in the terminal.

## Publish a live link
Run `npm run build`, then deploy the generated `dist` folder to Netlify, Vercel, or another static hosting service. Copy the public URL into the report PDF before submission. A localhost address is not a public submission link.

## Components
`Header`, `SummaryCard`, `TaskCard`, `TaskForm`, and `App` are defined in `src/main.jsx`.

## Features
Create, complete, delete, filter, and search tasks; task statistics; localStorage persistence; responsive navigation and layout; accessible form labels and controls.

Note: The example tasks are sample content. No account, server, or shared database is used.
